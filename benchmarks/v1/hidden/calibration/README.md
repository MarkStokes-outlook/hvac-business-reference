# Administrator/evaluator calibration exercises

These **synthetic observation records and author-scored anchors** check interpretation/admin readiness. They are not outputs of a candidate application, actual independent model assessments or evidence that any software passes V1. Independent reviewers should first receive the observation sections without the author anchor sections, score from the scenario oracle and canonical material, then compare and record disagreement using the ordinary assessment/adjudication contract. Never export these to the system under test.

The tool smoke checks additionally create synthetic assessment files to check arithmetic, stage completeness, critical caps, comparability and missing-run verdicts. Schema/cap tests do not verify model judgement. Before approved comparable release, record a second evaluator/administrator's actual calibration under `freeze-checklist.md`; the author has not claimed that review.
